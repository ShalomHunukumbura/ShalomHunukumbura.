I build production software for business, taxation and compliance, end to end: data model, API, frontend, deployment, and the incident response when something breaks in production.

Currently a Software Engineer at **Xaventra**, working on **BizAdvisor**, a 15-service platform that handles taxation, accounting, company incorporation and compliance workflows. Before that I worked on **Neurux**, a domain-specific AI assistant for finance and compliance built on retrieval-augmented generation.

**At work, so far**

- 460+ commits and 45+ merged pull requests on a six-engineer team, around 20% of releases
- Contributed to 140+ REST endpoints across FastAPI and Flask services on PostgreSQL
- Own features across 12 services, from schema to release: invoicing, payments, promotions, incorporation
- Wrote 46 Alembic migrations and maintain 8 GitHub Actions workflows, including automated migration checks
- Built RAG pipelines and prompt structures that kept LLM answers grounded in finance and compliance context
